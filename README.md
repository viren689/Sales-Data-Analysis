# Week 3 - Sales Data Analysis

## Description

This project uses Python and Pandas to analyze a simple sales dataset.

## Features

- Load CSV file
- Explore dataset
- Handle missing values
- Remove duplicates
- Calculate sales metrics
- Find best-selling product
- Generate formatted report

## Technologies Used

- Python 3
- Pandas

## Installation

Install pandas:

```bash
pip install pandas
```

Run the project:

```bash
python sales_analysis.py
```

## Files

- sales_analysis.py
- sales_data.csv
- analysis_report.md
- requirements.txt
