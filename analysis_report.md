# Sales Data Analysis Report

## Project Overview

This project analyzes a sales dataset using the Pandas library in Python.

## Objectives

- Load data from a CSV file.
- Explore the dataset.
- Handle missing values.
- Remove duplicate records.
- Calculate important sales metrics.
- Generate a sales report.

## Dataset Information

- Rows: 10
- Columns: 4

Columns:
- Product
- Quantity
- Price
- Total_Sales

## Data Cleaning

- Filled missing Quantity values with 0.
- Calculated missing Total_Sales using Quantity × Price.
- Removed duplicate rows.

## Metrics Calculated

- Total Revenue
- Average Sale
- Highest Sale
- Lowest Sale
- Best Selling Product

## Conclusion

The project successfully demonstrates how Pandas can be used to analyze sales data and generate useful business insights.
